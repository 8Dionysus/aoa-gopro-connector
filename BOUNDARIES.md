# Boundaries

| Territory | Owner |
| --- | --- |
| Camera profiles, domain state, plans, receipts, transports, stream/media manifests, Labs compiler, replay, CLI, local daemon | `aoa-gopro-connector` |
| USB/NCM, Bluetooth, Wi-Fi, permissions, host packages, secrets, storage, thermal and resource facts | `abyss-machine` |
| Long-running deployment, authenticated read plane, approved-effect bridge, service lifecycle and live canary | `abyss-stack` |
| Audio, motion, object, pose, ASR and VLM implementations | Named perception/model providers |
| Decisions to observe, record, notify and retain | Agent/policy owner |
| Named eval results, verdicts and promotion | `aoa-evals` |
| Shared measurement grammar and federation | `aoa-stats` |
| Derived capability and owner navigation | `aoa-kag` |
| Direction, irreversible actions and human acceptance | Operator |

The connector supplies local adapters and owner-qualified evidence. It does not
copy a neighboring owner's canonical contract into this repository or use a
later proof layer to repair a missing lower-layer receipt.
